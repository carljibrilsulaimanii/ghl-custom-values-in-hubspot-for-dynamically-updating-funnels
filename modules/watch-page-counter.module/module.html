The fields hold raw HubSpot ids, so the published page shipped rules like: html:not(.fc-open) hs_cos_wrapper_module_1234567890123 { display:none } Those are TYPE selectors, not ID selectors - there is no element, so they matched nothing. The form never hid and the join link never appeared.
